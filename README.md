A small Node 22 program that hands the address of the entry's X post to the make.fun grader: it copies POST.json into /output, where the house reads the post and counts its replies, reposts and quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
